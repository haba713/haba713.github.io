# haba713.github.io

Root of the GitHub Pages user site `https://haba713.github.io/`, built by GitHub Pages' Jekyll
from `index.md` (default theme, no workflow).

- `robots.txt` points crawlers to the sitemaps of the project sites, e.g.
  [paku](https://haba713.github.io/paku/) (`https://haba713.github.io/paku/sitemap.xml`).

Project sites live in their own repositories and are served under `/<repo>/`.
